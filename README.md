# T-Flex — 3D-фигурки

Проект подготовки художественных 3D-фигурок для T-FLEX CAD и 3D-печати.

Рабочие изменения выполняются в отдельных ветках и проходят проверку перед слиянием в `main`.

**Внимание:** полигональные модели STL/OBJ — не параметрические CAD-тела. Подготовка геометрии и импорт в установленный T-FLEX проверяются отдельно.
