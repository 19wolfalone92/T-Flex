# План и статус T-Flex Figurine Studio — 18.11.2026

## Реализовано (по коду)
- [x] API Tripo H3.1: авторизация через существующий GitHub Secret `TRIPO_AL` (реальная read-only проверка успешна).
- [x] H3.1 detailed geometry: `sculpt` и `display` (8K PBR) + `parts` с безопасными несовместимыми параметрами.
- [x] Multi-view input: настоящие front/left/back/right фото через file_tokens, тестируется порядок и валидация.
- [x] Optional Tripo image→synthetic-views→model: **две отдельные платные операции**, различать от реальных фото.
- [x] Meshy 7.1: code-only адаптер с supported Ultra 4K для single, Ultra 2K для multi; лицензия/ключ GitHub отдельно.
- [x] Explicit --yes-spend-credits на все платные задачи, default dry-run, нет автоматического повторения POST.
- [x] `tflex-reference`: offline диагностика фотографий и списка ракурсов.
- [x] `tflex-audit`: watertight, winding, degeneracy, separate shells, volume, caveats.
- [x] `tflex-pipeline`: единый геометрический preflight → STL/OBJ → manifest и отчёты.
- [x] `scripts/blender_review.py`: 4 ортографических ракурса + топологический отчёт (скрипт без нативной проверки в Blender).
- [x] `tflex-contact-sheet`: сравнение 4 ракурсов 2×2.
- [x] Unit tests + GitHub Actions для Python 3.10/3.11/3.12, проверка статического разбора Blender-скрипта.

## Реально не завершено
- [ ] Тест платной генерации Tripo на конкретной художественной фигурке с проверкой GLB (без пользовательского промпта/фото задача не запускалась).
- [ ] Экспериментальное сравнение одной реальной фигуры в Tripo и Meshy с визуальной разметкой: расходы только по прямому согласию владельца.
- [ ] Проверка Blender-скрипта на установленном Blender и установка 3D Print Toolbox.
- [ ] Автоматическая оценка толщины, коллизий, стабильности, опор без ложных гарантий.
- [ ] Верификация в слайсере и тестовая печать.
- [ ] Проверка на Windows версии/лицензии T-FLEX, затем нативный Open API плагин.
- [ ] Полуавтоматическая ремеш/художественная коррекция с проверкой сохранности черт лица и мелких элементов.

## Правила качества
- Рендерные 8K текстуры не подменяют геометрическую детализацию.
- Четыре AI-угла из одной фотографии не считаются четырьмя независимыми фотодоказательствами.
- Никаких заявлений "готово к печати" только на основании watertight.
- Никаких API-ключей и личных фото в git.
- Не запускать несколько кредитных генераций без явного согласия и расчёта расходов.
