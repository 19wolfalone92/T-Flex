## Оплата и секреты

Meshy расходует кредиты при генерации: автоматические платные задачи не запускать без отдельного запроса. Секреты, ключи, токены в git не добавлять. Поскольку репозиторий публичный, исходные фотографии людей и приватные скульпты не сохранять в GitHub.
