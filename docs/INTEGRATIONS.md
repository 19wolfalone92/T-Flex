Пользователь сообщил, что **создал Tripo API ключ**, но он хранится в GitHub Actions Secret с именем **TRIPO_AL** (по сообщению пользователя). В workflow значение передаётся только как переменная окружения **TRIPO_API_KEY**. **Реальная авторизация Tripo проверяется отдельным GitHub Actions запуском; читать ключ из чата нельзя.**

Не путать успешный CI с работой реального API или с импортом в установленный T-FLEX. Генерация может списывать кредиты. Программа требует явный флаг --yes-spend-credits; плановые автоматические расходы отключены.
