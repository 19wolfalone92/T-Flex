# Импорт фигурок в T-FLEX CAD

## Как импортировать полигональную модель

1. Получить GLB, OBJ или STL из Meshy 3D.
2. Проверить топологию и направление оси вверх: tflex-figurines inspect INPUT.
3. При необходимости исправить модель в Blender (замкнутая поверхность, отдельные части, ориентация, толщина).
4. Выполнить tflex-figurines prepare INPUT --height-mm 120 --up-axis y --output-dir exports.
5. Открыть T-FLEX CAD на Windows и использовать команду 3D-изображение / Вставить 3D изображение для OBJ или STL (название отличается по версии).
6. Проверить масштаб в мм, ориентацию, положение основания и наличие всех частей.
7. Если модель идёт на 3D-принтер — проверить её в слайсере; данный скрипт не рассчитывает толщины, опоры или пригодность печати.

## Важно про форматы

- OBJ, STL, GLB — полигональные форматы, при вставке в T-FLEX могут рассматриваться как 3D-изображение, а не полноценное изменяемое параметрическое тело.
- STEP пригоден для геометрии CAD, но не возникает автоматически из треугольной сетки без реконструкции поверхностей; обещать прямую конвертацию скульпта в редактируемую CAD-модель нельзя.
- STL не содержит достоверного указания миллиметров. Здесь координаты записываются в мм; при открытии обязательно проверяйте единицы.
- При ошибке OPEN_MESH требуется ремонт в скульптинге/mesh-редакторе. Автоматическое закрытие всех отверстий сознательно не реализовано.
- Если вам нужны текстуры, сохраните оригинальные GLB/OBJ+MTL+изображения Meshy: наш OBJ-экспорт ориентирован на проверенную геометрию.

## T-FLEX Open API

Интеграция в виде установленного T-FLEX-плагина пока не реализована. Для неё нужны версия CAD, тип лицензии и Windows-среда с установленным T-FLEX. В некоторых бесплатных/учебных редакциях сторонние Open API приложения недоступны.
